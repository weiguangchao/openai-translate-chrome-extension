# Page checks

YouTube: set media `captions` to the requested source language, such as `"en"`, and seek into speech. The player enables CC and selects the track; missing languages fail with the available list. On traced tabs, media waits for a parsed caption in the selected language and rejects a source matching the translation target. Inspect player/media errors before method/timeout changes. Native media errors fail with code/message, and media timeouts retain page and network state. HTTP 200 may contain `STREAM_PROTECTION_STATUS`, `ump.spsrejectfailure`, `HTML5_SPS_UMP_STATUS_REJECTED`. `media` fails with `YouTube refused playback: LOGIN_REQUIRED: …` when YouTube asks this network to prove it is not a bot; no retry or flag fixes it, so measure X or switch networks. `media` waits out ads before it seeks, and traces that saw an ad are invalid. To read caption text, use the request the player made; a fetch of `captionTracks[].baseUrl` without its PO token returns HTTP 200 with an empty body.

X: confirm main video, subtitle language, track mode, loaded/active cues and source. Fresh profiles start with X's subtitle track disabled, so Subline shows nothing; the plan's X cases set media `captions` to turn the first native subtitle track on. React may expose native cues without full HLS at `playerApi.video.hlsJs`. Model mode/successful replies do not prove timely prefetch; check replies precede caption changes.

Inspect screenshots/`overlay`; fit both lines, scroll clear of fixed login/reply panels, record viewport/scroll. DOM visibility cannot rule out occlusion. Never hide elements with CSS for a pass. Label paused diagnostics separately; they cannot replace playback traces.
