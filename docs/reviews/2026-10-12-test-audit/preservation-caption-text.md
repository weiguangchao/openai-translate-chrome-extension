A wrong production divisor using translationBatchLimit would pass. I reported this to root. Root changed only the test dependency fixture, preserving real limits and setting segmentCaptions to translationBatchLimit + 1. The existing long-caption numbering declaration now exercises different values without a production injection hook. I inspected the updated keeper. Its generation and expected labels use segmentCaptions; the timeline implementation uses that constant. Root owns the control and single-divisor mutation execution.
